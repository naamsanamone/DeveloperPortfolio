## 🌐 1-Click Deployment (Vercel)
1. Push this folder to GitHub as a new repository (e.g., `portfolio` or `saivenkat-dev`).
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository.
4. Framework preset: **Vite**.
5. Click **Deploy**! (Ready in <30 seconds with 100/100 Lighthouse score).
